# Forestry maps

Interactive maps on forestry and forest-products topics, one per subfolder with its own `index.html`.

| Map | Description | Live demo |
|---|---|---|
| [`pulp-mills`](pulp-mills/) | US pulp mills, 1860–present — zoomable, pannable map with a play/scrub timeline of openings and closures, a click-to-pin detail card per mill, and support for loading your own CSV. | [Demo](https://pratyush-dh.github.io/forestry-maps/pulp-mills/) |

More maps will be added here over time.
